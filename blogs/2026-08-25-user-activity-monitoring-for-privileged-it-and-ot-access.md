User activity monitoring, or UAM, is the collection and analysis of evidence showing how identities interact with systems, applications, data, and devices. For privileged IT and OT access, its purpose is to reconstruct high-risk activity: who connected, which resource they accessed, what they did, when it happened, and whether the activity matched an approved task. UAM can include session recording, application and system logs, identity events, network telemetry, file activity, and command or input evidence.
